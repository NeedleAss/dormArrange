# 01 · 故事与路演

> 读者：全队，尤其是 17:00 留在桌前讲解的那位。
> ⚠️ 文中的具体数字（32 cm、4 步、48→86 等）是示意。**以演示时实际算出的结果为准**，彩排时替换。

## 1. 一句话

**不换宿舍、不动固定家具，用最少的调整，在方寸之间找回能学习、收纳和生活的空间。**

## 2. 名字：方寸

「方寸」有三层意思，正好对上三个关键词：

| 含义 | 出处 / 用法 | 对应关键词 |
|---|---|---|
| **方寸之地**：很小的空间 | 常用语 | 空间 |
| **方寸之心**：古人称心为"方寸"。徐庶说"方寸乱矣"，意思是心乱了 | 《三国志》 | 专注 |
| **寸阴**：一寸光阴 | "寸阴是竞" | 时间 |

收尾一句：**方寸之间，自有天地。** 宿舍没有变大，你在长大，对应关键词"成长"。

## 3. 痛点：为什么是现在、为什么是宿舍

- **规则把家具钉死了。** 学校《住宿注意事项》第 17 条：不得私自改变设施的位置和功能。床、桌、柜都动不了，**能动的只有你的东西，和你的时间。**
- **新生在开学前看不到宿舍。** 手上只有一张学长发的照片和一份"必带清单"：28 寸箱子塞不塞得进？收纳箱该买多高？电热水壶能不能带？
- **老生的书桌在一年里被慢慢淹没。** 整理一次要半天，大多数人选择"算了"，然后在 20 厘米宽的缝里写作业。
- **一个数字**（以实测为准）：书桌约 130×60 cm ≈ 0.78 ㎡；摊开一本书加一台笔记本只要 75×35 cm ≈ **0.26 ㎡**。**我们只需要找回三分之一张桌子。**

## 4. 故事主线：一个 EE 新生的四年

主角是一个虚构的电子系新生，叫「小 E」。

| 幕 | 画面 | 旁白要点 |
|---|---|---|
| **序 · 方寸** | 黑屏开机自检 → 巨号粗宋「方寸」 | "宿舍不是分配给你的一个盒子，而是一块你要与之**同步**的空间。" |
| **第零话 · 建模** | 线框宿舍从地砖网格里升起 | 开学前，小 E 拿到学长发的照片，数了数地砖：一排 5 块半，每块 60 cm，宽约 3.3 米。宿舍的 3D 模型就有了。 |
| **第一话 · 入住** | 物品一件件落进宿舍：绿、琥珀、青、红 | 24 寸箱子正好塞进桌下；28 寸只能放门口公共角落，得和室友商量；那个还没买的收纳箱，**高度别超过 32 cm**；电热水壶超过 1000W，禁止携带。**下单前该看哪个数，一目了然。** |
| **第二话 · 腾桌** | 红色六边形力场展开，5 件东西闪红 | 大二期中周，桌面被书、零食、快递盒淹没。小 E 不想全部重来。系统给出 4 步作战指令：快递盒扔掉；零食箱进桌下；书架满了，就先把用不上的旧讲义收到床尾，再把两摞书放上去。力场转绿，同步率从 48 升到 86。专注限界开始倒数 25:00。 |
| **第三话 · 换季** | 拖动月份，冬装从箱子里飞出、风扇飞进去；热力谱由红转绿 | 十一月，衣柜满了，冬装却要出来。电子系都懂**时分复用**：同一条信道按时间片轮流用。风扇和羽绒服从不同时在用，空着的行李箱就是现成的深层收纳。打开时分复用，最高占用率从 131% 降到 72%。 |
| **第四话 · 成长** | 时间轴回放四个学期，同步率曲线起落 | 入住、满桌、腾桌、换季……累计专注 120 小时。宿舍没有变大，你在长大。 |
| **尾声** | 「方寸」标题卡 | **方寸之间，自有天地。** |

### 5.3 互动版：观众上手，约 90 秒

1. 问观众："你桌上现在有哪些东西？"边听边把他说的打进 EP01 文本框，或者让他自己打字。
2. 点「解析」→「开始规划」，看看他的东西能不能放下。
3. 如果做了加分项「乱堆到桌面」（B6），切到 EP02 →「展开力场」→「执行」，现场帮他腾桌。
4. 最后说："投我们一票的话，记得选'方寸'。"

## 6. 评委问答准备

| 问题 | 回答要点 |
|---|---|
| 尺寸从哪来？准吗？ | 每个数都标了来源：实测、商品参数或估计。**不确定的不硬判**，而是给出"容差"，告诉你该去核对哪个数、上限是多少。宿舍尺寸可以用数地砖法校准。 |
| 为什么不做全局最优装箱？ | 3D 装箱是 NP 难问题，最优解往往反直觉，人不会照着摆。我们追求**最少调整、可执行、可解释**：贪心 + 一层级联，宿舍规模下 100ms 内出结果，每一步都能说清为什么。 |
| 和宜家、酷家乐这类家装软件有什么不同？ | 它们设计"能装修的家"。我们面对的是**家具不能动、四人共享、需求随时间变化**的宿舍。输出是"挪哪几件"，不是"买什么家具"。 |
| AI 用在哪？ | AI 负责**听懂你**：把自然语言或照片变成物品清单。算法负责**算对**：放置、腾挪、换季都是确定性算法。AI 不可用时自动用本地规则兜底，演示不依赖网络。 |
| 时分复用是噱头吗？ | 不是。可达空间有限是真实约束：过季物品集中进深层收纳和行李箱，把手边的空间让给当季物品。开、关两种情况的占用率对比是实际算出来的。 |
| 同步率怎么算？ | 公式公开：35% 放得下 + 25% 顺手（使用频率和位置匹配）+ 25% 专注区净空 + 15% 通道安全。三审决议「时 / 空 / 心」分别检查步骤数、空间和专注。 |
| 隐私呢？ | 全部本地运行。照片只有在你点击时才发给模型，不保存。 |
| 能推广吗？ | 宿舍模板是参数化的，换一组参数就能适配别的楼、别的学校；数地砖法人人都能用。 |

## 7. 评分维度对照（第二阶段：创意度、美观度、实用性、技术难度）

| 维度 | 我们的证据 |
|---|---|
| 创意度 | "方寸"三重含义的叙事；五话结构；**宿舍里的时分复用**；同步率与「时 / 空 / 心」三审 |
| 美观度 | EVA 风格的致敬界面：粗宋标题卡、警示条、线框 3D、六边形力场；整体统一 |
| 实用性 | 新生的**下单前容差清单**；老生的**最少步腾桌**；依据真实宿舍规定（违章电器、不得堵塞通道、不得改动设施） |
| 技术难度 | 2.5D 高度图装箱、带级联的最少移动规划、按月份的时分复用调度、three.js 实时补间动画、LLM 结构化解析加离线兜底 |

## 8. 互评策略（选手互评占 50%）

- **一眼吸引**：待机演示循环，路过的人 3 秒内能看到标题卡和 3D。
- **30 秒说清**：只讲一个新生、一个老生。
- **让人上手**：观众说出桌上的东西，现场给他腾桌。
- **记忆点**：方寸、时分复用、"高度别超过 32 厘米"、同步率。
- 互评每人最多勾选本赛道一半的队伍，**被记住**才能被勾选。
