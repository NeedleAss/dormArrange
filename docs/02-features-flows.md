# 02 · 功能与交互流程

> 读者：C 车道（主要）、A 车道。本文描述每个界面上**用户做什么 → 系统调用什么 → 画面怎么变**，以及验收标准。
> API 签名见 `03-architecture.md` §4，视觉细节见 `06-eva-style.md`。

## 0. 全局界面

```
┌ 顶栏 48px ─────────────────────────────────────────────────────────────────┐
│ 方寸 FANGCUN // DORM SPACE-TIME OPS │ EP02 腾桌 │ 14:52:07 │ AI ● ONLINE   │
├ 左栏 320px ──────┬──────────── 3D 画布 ─────────────┬─ 右栏 320px（监视器）┤
│ [0建模][1入住]     │                                  │ SYNC RATIO 同步率      │
│ [2腾桌][3换季]     │        线框宿舍 + 物品             │   86 %  ▁▃▅▆█          │
│ [4成长]           │                                  │ 三审决议 时│空│心      │
│ ───────────────── │                                  │ 分区状态（可滚动）      │
│ 当前话的面板       │                                  │ 警报流（最新在上）      │
├───────────────────┴──────────────────────────────────┴───────────────────────┤
│ 底栏 76px：EP02 步骤条 / EP03 月份滑块 / EP04 时间轴      │ 视角 ORBIT TOP SEAT │
└───────────────────────────────────────────────────────────────────────────────┘
```

- **顶栏**：系统名、当前话、实时时钟（mono）、AI 状态（ONLINE 绿 / OFFLINE 灰）。
- **右栏**：常驻的同步率、三审决议、分区状态、警报流。任何规划结果变化都会重算同步率（§6）。
- **底栏**：随当前话切换内容；右侧固定视角按钮。
- **快捷键**：0–4 切换各话；T 切换视角；空格 播放/暂停；F 展开力场（EP02）；L 锁定选中的分区。

## 1. 第零话「建模」EP00

**目的**：得到一间尺寸可信的 3D 宿舍，并看清每块空间的状态。

| 用户操作 | 系统 |
|---|---|
| 进入 EP00 | 显示标题卡；左栏出现参数表单，参数按「房间 / 门窗阳台 / 组合床单元」分组 |
| 修改任一参数（输入框或 ±5 步进） | `buildRoom(params)` → store.room → `scene.setRoom` 立即重建；该参数旁边的来源标签从"估"变为"实测" |
| 打开「数地砖」小工具 | 输入"块数 × 砖长（60/80/自定义）"，点「填入」后写回对应尺寸 |
| 选择"我是谁"（A/B/C/D） | 写入 store.owner；后续 EP01/EP02 都以这套单元为准；3D 中这套单元高亮 |
| 分区列表：点击 | `scene.focusOn(zoneId)` |
| 分区列表：锁定开关 | 更新 lockedZones → 分区状态变为"已完成"；规划时不再动它 |
| 「显示分区」开关 | 3D 中显示所有分区线框（状态色）和 keepClear 的红色斜线 |

分区列表每行显示：状态色点、名称、`tier`、占用率（mono 百分比）、锁图标。

**验收**

- 改房间宽度时，3D 宿舍实时变化。
- 能看出四套上床下桌、过道、门的开启扇区、阳台。
- 锁定分区后，它的颜色变绿并显示 LOCKED。

## 2. 第一话「入住」EP01：新生任务

**用户的问题**：我准备带来的这些东西，哪些能放下，哪些需要换位置，哪些尺寸还不能确定？

### 2.1 输入（三种方式可以混用）

1. **大文本框**：随便写或粘贴，例如"24寸行李箱，两床被子，27寸显示器，书20本……"
2. **「载入新生示例」**：填入 `PRESETS.freshman`。
3. **物品库下拉**：搜索后添加；每件物品可以展开编辑名称、W×D×H、来源（实测 / 商品参数 / 估计 / 未知）、使用频率、季节。
4. **（加分）「拍照识别」**：调用 `aiParsePhoto`。

点「解析」后，调用 `ai.aiParseItems(text, { owner })` 得到物品清单，显示为可编辑的表格，标题栏注明来源（AI / 本地规则）。

### 2.2 规划

点「开始规划」后：

1. 调用 `planMoveIn(room, items, { owner, lockedZones })`。
2. 把结果写入 store：placements、itemStates（verdict.status → 视觉状态）、fitReport、sync。
3. 3D 中物品依次落位（setItems 带补间）；放不下的物品排进门外的滞留区。

### 2.3 结果区

**顶部**：五个统计徽章，可点击筛选。

| 徽章 | 颜色 |
|---|---|
| 能放下 N | 绿 |
| 需换位置 N | 琥珀 |
| 尺寸待定 N | 青 |
| 放不下 N | 红 |
| 禁止携带 N | 红色闪烁 |

**列表**：按状态分组。每行显示物品名、位置（分区 label）、一句话原因。

**点击一行**：

- 3D 中执行 `focusOn(itemId)`，并选中该物品。
- 展开详情卡，内容如下：

| 状态 | 详情卡内容 |
|---|---|
| 能放下 | 位置 + 尺寸 + 来源 |
| 需换位置 | 原因列表 + 建议 |
| **尺寸待定** | **容差句**："下单前确认：宽 ≤ 52、深 ≤ 38、高 ≤ 32 cm 就能放进「A 桌下」"；同时 3D 显示绿色虚线幽灵盒（`showTolerance`） |
| 放不下 | need 句："「A 桌下」目前最大空位约 40×34×70 cm" + 建议 |
| 禁止携带 | 规则原因（附第 12 条出处） + 替代建议 |

**底部**：「导出购物前核对清单」，把所有"尺寸待定"的容差句复制到剪贴板。这是新生最直接能用上的产出。

### 2.4 边界情况

- **输入为空**：「开始规划」不可点。
- **AI 失败**：顶栏 AI 状态变 OFFLINE；结果标题写"本地规则解析"；流程不中断。
- **0 件放不下**：警报流推一条绿色的"全部可放下"。

### 2.5 验收

用新生示例走通全流程，五类里至少出现四类。点"尺寸未知的收纳箱"能看到容差句和幽灵盒；点电热水壶能看到"额定功率超过 1000W"。

## 3. 第二话「腾桌」EP02：老生任务

**用户的问题**：东西已经摆满了，我不想全部重来，只想腾出一块能摊开书和电脑的桌面。

| 步骤 | 用户 | 系统 |
|---|---|---|
| ① | 「载入乱桌示例」，或沿用 EP01 的结果 | items、placements 换成 `PRESETS.messyDesk`；镜头 `focusOn('A.desk')` |
| ② | 选专注区预设：仅笔记本 35×25 / **书+笔记本 75×35** / 双开书+笔记本 90×40，或拖动两个滑块自定义 | 更新 store.focusSpec |
| ③ | 「展开专注力场」 | 调用 `planFocusField(...)`，结果暂存；`scene.showFocusField(plan.focusBox)`；冲突物品 → `conflict`；警报 "专注区内检测到 N 件物品" |
| ④ | 查看「作战指令」 | 列出步骤（第 k 步……）；底部显示 metrics：挪 N 件 · 约 M 秒 · 净空 0.26㎡；三审决议显示**执行后**的预判 |
| ⑤ | 「执行」 / 单步 / 拖动步骤条 | `scene.playSteps(steps, { onStep })` 播放动画，onStep 更新 stepIndex 并高亮当前步骤；拖动步骤条时用 `applySteps(placements, steps, i)` + `setItems` 跳转 |
| ⑥ | 动画结束 | placements ← placementsAfter；`setFocusFieldState('clear')`；同步率 count-up 到新值；三审若全员承认，显示横幅 |
| ⑦ | 「开始专注」 | 专注限界覆盖层显示 25:00 倒计时；`setCamera('seat')`；结束后 focusMinutes += 25，并推警报"专注完成 +25 min" |

**边界情况**

- **没有冲突**：直接显示"专注区已经净空"，按钮变为「开始专注」。
- **有 unresolved**：步骤列表末尾显示红色条目及建议。如果有 `alternatives`（加分项），显示「加购方案」卡片，例如"多花 ¥39 买增高架，少挪 2 步"，点击后切换到该方案。
- **锁定的分区**：分区里的东西不会被挪；锁住的分区不会成为落点。

**验收**：乱桌示例中，力场先红后绿，步骤 ≤ 6，同步率上升，三审至少有两票承认，座位视角能看到干净的桌面。

## 4. 第三话「换季」EP03

**故事**：空间不够，就用时间来换——时分复用。

| 控件 | 行为 |
|---|---|
| 进入 EP03 | 若 tdmPlan 为空：先显示"计算中"，然后 `planSeasons(room, items, { owner, tdm, compare: true })` |
| 月份滑块（底栏，9 月 → 次年 8 月） | placements ← `byMonth[m].placements`，3D 补间；左栏显示 `diffMonths(prev, cur)` 生成的换季清单，例如"取出「羽绒服」：从行李箱里放到 A 衣柜挂衣区" |
| 「时分复用」开关 | 切换 tdm 后重新计算；对比卡显示"开启：最高占用 72%，0 个月溢出 / 关闭：最高占用 131%，4 个月溢出" |
| 时空占用谱 | 分区 × 月份热力格；点击格子跳到对应月份并 `focusOn(zoneId)` |
| 「自动播放一年」 | 每 0.8s 前进一个月 |

**验收**：从 10 月拖到 12 月时，羽绒服和冬被从行李箱或床尾进入衣柜和床上，风扇收进箱子；打开和关闭时分复用的对比数字不同，打开时更好。

## 5. 第四话「成长」EP04

| 控件 | 行为 |
|---|---|
| 「保存快照」 | 弹出小表单：label + 学期（大一上…大四下）；保存当前 items、placements、sync、focusMinutes；可选调用 `scene.snapshot()` 生成缩略图 |
| 底栏时间轴 | 每个快照是一个菱形节点（上方同步率，下方学期）；点击节点加载该快照 |
| 「回放」 | 依次加载相邻快照，每段之间 setItems 补间 1.2s，标题卡式字幕显示学期名 |
| 「载入成长示例」 | `PRESETS.growth`（4 个快照：入住 → 大一下 → 满桌 → 腾桌后） |
| 统计区 | 同步率随学期变化的折线、累计专注时长、物品总数变化 |
| （加分）成长预测 | `predictGrowth`："按每学期 +5 本书，大二下书架会满" |

**验收**：载入示例后能点击切换四个快照；回放能连续播放；折线正确。

## 6. 同步率与三审决议的刷新时机

下列事件之后调用 `computeSync(room, items, placements, ctx)`，并把 `{ t, total, label }` 追加到 syncHistory：

| 事件 | ctx |
|---|---|
| EP01 规划完成 | `{ owner, decisions }` |
| EP02 展开力场 | 预判，`{ focusBox, moves }` |
| EP02 执行完成 | `{ focusBox, moves }` |
| EP03 月份切换 | `{ owner, swaps: 换季步骤数 }` |
| EP04 加载快照 | `{ owner }` |

## 7. 空间状态（空白 / 设计中 / 已完成）

- **规则**：已锁定 → 已完成；有物品 → 设计中；否则 → 空白（docs/03 §5）。
- 右栏分区状态列表和 3D 分区线框必须同步。
- 在 EP00 打开「显示分区」，或在任何话中选中某个分区时，在 3D 中显示。

## 8. 待机演示（加分，C5）

60 秒无操作后自动进入演示循环：

开机序列 → EP00（转一圈镜头）→ EP01（载入示例并规划）→ EP02（展开力场，执行）→ EP03（自动播放一年）→ EP04（回放）→ 回到开头。

任何点击或按键都会退出。17:00 展示时，路过的人一眼就能看到完整故事。

## 9. 文案规范

- 中文为主；英文代号只用在标签和按钮的副标题上。
- 所有给用户的话**说人话、可执行**：写"把零食箱移到桌下（约 85 cm）"，不写"relocate item-012"。
- 数字一律带单位，用 mono 字体。尺寸写成 `W×D×H cm`。
