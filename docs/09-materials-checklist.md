## 🔴 P0：14:50 前（决定 3D 和算法可不可信）

### 1. 宿舍照片：每张从固定角度拍一张即可

| # | 拍什么 | 用途 |
|---|---|---|
| 1 | 门口往里的全景 | 核对整体布局、过道宽度 |
| 2 | 自己的书桌正面（越乱越好） | EP02 乱桌预设；对照 3D 座位视角 |
| 3 | 衣柜门打开 | 挂杆高度、底部空间 |
| 4 | 桌下 | 桌下净高、侧边空间 |
| 5 | 阳台 | 阳台进深、洗漱台位置 |
| 6 | 床尾 | 深层收纳空间 |

放在 `assets/dorm-photos/`，文件名例如 `01-全景.jpg`。

### 2. 关键尺寸：填进 `assets/measurements.md`

能让在宿舍的室友现场量最好；不能的话用下面的办法估。

| 参数（docs/07 §1） | 含义 | 默认估计 | 实测 | 怎么得到的 |
|---|---|---|---|---|
| room.w | 房间宽（左墙到右墙） | 330 | | |
| room.d | 房间深（门墙到阳台墙） | 560 | | |
| room.h | 层高 | 300 | | |
| door.w / door.x | 门宽 / 门左边框离左墙的距离 | 90 / 230 | | |
| balcony.d | 阳台进深 | 140 | | |
| unit.len / unit.depth | 组合床沿墙长 / 离墙深 | 210 / 95 | | |
| unit.deskLen × deskDepth × deskH | 书桌长 × 深 × 桌面高 | 130 × 60 × 75 | | |
| unit.hutchY / hutchH | 桌上书架层板高度 / 可用净高 | 130 / 40 | | |
| unit.wardrobeLen × wardrobeDepth × wardrobeH | 衣柜 宽 × 深 × 高 | 70 × 60 × 170 | | |
| unit.rodY | 挂衣杆高度 | 160 | | |
| unit.underDeskH | 桌下净高 | 70 | | |
| unit.bedY | 床板离地高度 | 175 | | |

**没有卷尺时怎么估**：

- **数地砖**：先确认砖长，常见 60cm 或 80cm，可以拿 A4 纸比一下（29.7 × 21.0cm）。然后数块数，块数 × 砖长 = 长度。
- **用参照物**：门洞宽一般 80–100cm；标准 A4 纸长 29.7cm；550ml 矿泉水瓶高约 21cm；身份证宽 8.56cm。
- 照片里能看到参照物时，按比例估算，在"怎么得到的"一栏写"照片估"。

## 🟠 P1：15:20 前（让演示数据真实）

### 3. 新生清单

- 找一份真实的"新生入学必带清单"，来源可以是学校、学长或社交平台，或者让一个队友回忆自己大一带了什么。
- 越像真人写的越好，可以有口语、数量、"大概多大"这类描述，用来展示解析能力。
- 存成 `assets/item-lists/freshman.txt`，交给 B 车道写进 `PRESETS.freshman`。

### 4. 乱桌清单

对着照片 2 把桌上的东西逐件列出，写成"名称 + 大概位置"，例如"零食箱 桌面中间偏右"。

存成 `assets/item-lists/messy-desk.txt`，交给 B 车道写进 `PRESETS.messyDesk`。

### 5. 常见物品的商品参数

去购物平台截图或记下 长 × 宽 × 高，用来核对 docs/07 §2 的物品库：

- 行李箱 20 / 24 / 28 寸
- 大号、中号收纳箱
- 24 / 27 寸显示器（含底座）
- 显示器增高架
- 桌面置物架
- 真空压缩袋的压缩比
