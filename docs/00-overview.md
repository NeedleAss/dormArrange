## 2. 范围（MoSCoW）

| 级别 | 内容 |

| **Must 必须** | EP00 参数化建模，3D 实时显示 · EP01 入住全流程（规则解析即可）· EP02 腾桌全流程（力场 + 作战指令 + 动画）· EVA 外壳（标题卡、同步率、三审决议）· 作品包 |
| **Should 应该** | AI 文字导入 · EP03 换季（12 个月或 4 季）· 专注限界番茄钟 · 分区状态显示 |
| **Could 加分** | EP04 成长回放 · 待机演示 · 加购方案 · 照片导入 · 发光后期 · 成长预测 · 乱堆到桌面（观众互动） |
| **Won't 不做** | 账号登录 · 多人实时协作 · 真实 3D 模型或扫描 · 移动端适配 · 从照片自动测量尺寸 |

## 3. 落后时的砍需求顺序

1. 照片导入
2. 加购方案、成长预测
3. 发光后期
4. 待机演示
5. EP04 只留"预设快照 + 点击切换"
6. EP03 只做 4 个季节

**Must 级别的内容一律不砍。**

## 6. 审查节奏：怎么用总架构

每到一个检查点：

1. 各车道先推送。
2. 在 claude.ai 对话里说一句"CP1 推了"。
3. 总架构拉取仓库，对照下表审查，给出按车道分组的问题清单（只指出问题、给修改方向，不写代码）。

| 检查项 | 内容 |
|---|---|
| 契约 | 函数签名、字段名是否与 docs/03 §4、docs/04 一致 |
| 所有权 | 有没有人改了不属于自己车道的文件 |
| 安全 | 有没有 key、`.env.local` 被提交 |
| 授权 | 有没有原作素材，或来源不明的字体和图片 |
| 一致性 | 状态色、术语、文案是否统一 |
| 演示路径 | docs/01 §5 的脚本能否走通 |

## 7. 风险与对策

| 风险 | 征兆 | 对策 |
|---|---|---|
| 两个智能体改同一个文件 | git 冲突；对方的代码被覆盖 | 严格按 AGENTS.md §5 的所有权；人类盯住 diff；`git pull --rebase` 后再推 |
| 接口对不上 | import 报错；字段 undefined | 只认 docs/04；B0 先推 stub；改契约走 tasks/CHANGES.md |
| 规划算法来不及 | 15:20 时 B2 还没完成 | 先让 EP01 用"能放就放"的简化版（只用 store 模式 + 五分类），容差改为只算 maxH |
| 3D 性能差 | 帧率 < 30 | 关闭 bloom；pixelRatio 降到 1；物品描边改用单个 LineSegments 合批 |
| AI 接口不通 | 401 / 超时 | 不影响 MVP：走规则解析；D 车道转去做集成走查 |
| 尺寸数据不可信 | 评委追问 | 所有估计值都标"估"；演示时强调"容差"和"数地砖校准" |
| 时间不够 | 16:20 时 EP02 仍不稳定 | 按 §3 砍；16:35 一定要先传保底版 |
| 版权与授权 | 有人往仓库里放了原作截图 | 只在群里看参考图；提交前在 assets/ 和 public/ 里查一遍 |
